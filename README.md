# Simple Text Editor 📝

## 📌 Overview

This is a Java-based console application that simulates a simple text editor using Object-Oriented Programming (OOP) concepts. The system allows users to add, display, reverse, and clear text using a mutable StringBuffer.

## 🚀 Features

* Add text to the document
* Display current text
* Reverse existing text
* Clear all text
* Encapsulated text management
* Simple and modular design

## 🧠 Concepts Used

* Classes and Objects
* Encapsulation
* Constructors
* StringBuffer
* Method Design
* State Management

## 🛠️ Technologies Used

* Java
* VS Code / Eclipse

## ▶️ How to Run

1. Compile the program:
   javac Main.java

2. Run the program:
   java Main
